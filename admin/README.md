# Admin Folder

This folder contains the admin-facing portal documentation for SNSU-FRMS.

## Pages
- `admin/index.html` — landing page for admin users.

## Notes
Admin and monitoring functionality is available through the root-level pages:
- `index.html` for dashboard summaries
- `notifications.html` for request logs
- `notes.html` for request review and status updates
- `help.html` for FAQ content management

These pages share the same `css/style.css` and `js/script.js` assets used by the student experience.
