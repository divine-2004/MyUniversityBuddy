# Shared Folder

This folder documents shared assets and contracts for SNSU-FRMS.

## Shared files
- `css/style.css` — shared styling used across the app.
- `js/script.js` — shared behavior for login, profile, requests, dashboard, notifications, and FAQ interactions.

## Storage Contract
Shared browser storage keys used by the application:
- `loggedIn`
- `userRole`
- `profileData`
- `facilityRequests`
- `fmrmsNotifications`
- `helpMessages`

These keys are used across both student and admin views.
